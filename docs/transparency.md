# Transparency and Security

## Source availability

The main Opus Client, Launcher, and Runtime implementations are proprietary. Opus Optim is publicly available in its own repository.

## Release integrity

Official release artifacts and their verification details will be documented when public releases are available. Do not rely on unofficial binaries claiming to be Opus.

## Audit scope

Any public security, privacy, or module-activity documentation will define exactly which builds and events it covers. A local application log alone does not independently prove the completeness of recorded activity.

## Reporting vulnerabilities

Please use the project's officially published security contact or GitHub security reporting settings when available. Do not post sensitive proof-of-concept data publicly.
